## ResourcepacksLib

版本：1.21.11
加载器：fabric_loader0.141.6+1.21.11
### 功能

保存资源包，光影包,钠配置记录

文件目录: config/resourcepackslib/presets.json

### 操作

`/reslib save <id>` 保存配置

`/reslib apply <id>` 导入记录

`/reslib list` 列出记录

`/reslib delete <id>` 删除记录

`/reslib rename <旧id> <新id>` 重命名

`/reslib open` 打开管理界面

### 依赖
Fabric Loader 0.20.1+

Fabric API 0.141.6+1.21.11

Fabric Language Kotlin

Iris（可选）

Sodium（可选）
